# Résumé

Source content and build scripts for Kieran's curriculum vitae (CV), compiled
from LaTeX to PDF. Releases are tagged in Git and built automatically by CI.

The capitalized words REQUIRED, MUST, MUST NOT, RECOMMENDED, SHOULD,
SHOULD NOT, OPTIONAL, and MAY are to be interpreted as described in
[IETF RFC 2119](https://www.ietf.org/rfc/rfc2119.txt).

## Tech stack

- LaTeX (`pdflatex`), compiled inside the [`kieranpotts/latex`](https://hub.docker.com/r/kieranpotts/latex)
  Docker image — no local LaTeX install is required.
- Docker, to run the compiler consistently across host systems.
- GitHub Actions, to build the PDF and attach it to GitHub releases on tag push.

## Project structure

- **[src/kieran-potts-cv.tex](./src/kieran-potts-cv.tex)** \
  The CV source, compiled by `pdflatex`.

- **[run/start](./run/start)**, **[run/build](./run/build)**, **[run/stop](./run/stop)** \
  Dev scripts. `start` launches a persistent `latex_daemon` container;
  `build` runs `pdflatex` inside it, outputting to `dist/`; `stop` tears the
  container down.

- **[dist/](./dist)** \
  Build output, including `kieran-potts-cv.pdf` and other compiler artifacts.
  Not committed as source of truth — regenerated by `run/build`.

- **[CHANGELOG.md](./CHANGELOG.md)** \
  Per-release notes, aligned with Git tags.

## Tools

- **`./run/start`** to start the persistent LaTeX container.
- **`./run/build`** to compile `src/kieran-potts-cv.tex` to `dist/kieran-potts-cv.pdf`.
- **`./run/stop`** to stop the container.

## Rules

- MUST run `chmod +x run/*` after cloning, since the scripts are not
  executable by default on all systems.

- RECOMMENDED to tag releases as `v[major].[minor].[patch]` with an annotated
  tag (`git tag -a`), including a summary of changes in the tag message, and
  push with `git push --follow-tags`. CI creates the GitHub release and
  attaches the compiled PDF automatically.

- Release notes SHOULD be formatted using Markdown, consistent with
  `CHANGELOG.md`.
